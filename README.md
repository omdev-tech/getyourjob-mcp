# GetYourJob extension for Gemini CLI

Search French IT jobs and freelance missions, run AI matching on your profile, track your
applications and generate cover letters from [Gemini CLI](https://github.com/google-gemini/gemini-cli).

## Install

```bash
gemini extensions install https://github.com/omdev-tech/getyourjob-gemini-extension
```

On first use, Gemini CLI opens the GetYourJob OAuth sign-in in your browser.
You need a free account on [getyourjob.pro](https://getyourjob.pro/auth/register).

Full documentation and the tool list: https://getyourjob.pro/mcp
